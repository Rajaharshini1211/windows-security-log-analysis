# Windows Security Log Analysis 🛡️

## Overview

This project demonstrates a beginner-level cybersecurity investigation using Windows Security Event Logs.

The project focuses on identifying failed login attempts and analyzing whether the activity could indicate unauthorized access or a brute-force attack.

## Objectives

- Understand Windows Security Event Logs
- Analyze failed login events
- Investigate suspicious authentication activity
- Identify possible indicators of compromise
- Document security findings
- Recommend defensive measures

## Tools Used

- Windows Event Viewer
- Windows Security Logs
- GitHub
- Markdown

## Important Event IDs

| Event ID | Description |
|----------|-------------|
| 4624 | Successful logon |
| 4625 | Failed logon |

## Investigation Process

1. Collect Windows Security Events
2. Filter for Event ID 4625
3. Analyze failed login attempts
4. Examine account and network information
5. Identify suspicious patterns
6. Document findings
7. Recommend mitigation

## Findings

The investigation will focus on repeated failed authentication attempts and other suspicious login patterns.

## Security Recommendations

- Use strong passwords
- Enable Multi-Factor Authentication
- Monitor failed login attempts
- Restrict unnecessary remote access
- Investigate suspicious authentication activity

## Learning Outcomes

This project helped develop practical skills in:

- Security log analysis
- Authentication monitoring
- Incident investigation
- Basic threat detection
- Security documentation
